# Enterprise AI Project Template

**Elevator Pitch:** A standardized AI engineering boilerplate.

## Architecture
* Infrastructure: Ubuntu Server, Docker, Tailscale
* Compute: Llama 3.1 8B via Ollama, LangChain
* Backend: Node.js / Python

## Quick Start
1. Clone the repository
2. Copy .env.example to .env
3. Run docker compose up -d --build
